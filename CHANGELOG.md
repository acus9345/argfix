# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-31

### Added

- `coerce()` and `coerceSync()` for any Standard Schema or JSON Schema.
- Thirteen rules for wrong types, enum case, JSON strings, stray whitespace, arrays and nulls.
- Every fix is reported with its path, old value, new value and rule.
- `skip` and `maxChanges` options.
